# F1 Championship Prediction Engine

A quantitative finance-inspired machine learning project that predicts Formula 1 championship probabilities using Python, statistics, data science, and Monte Carlo simulation.

---

## Project Goal

The goal of this project is to build a professional, research-oriented prediction engine capable of estimating Formula 1 championship outcomes using historical race data, statistical modeling, and machine learning techniques.
